# Video 7 — The Big Picture: How It All Connects

## 5. How the Four Modules Connect (The Big Picture)

Although the chart presents Stock, Staff, Display, and Communication as four separate swim-lanes, they are deeply interdependent in practice:

- **Stock feeds Display** — you cannot execute a planogram correctly if the SKU isn't physically at the store (this is why the Display process checks "SOH versus physical" stock during replenishment visits).
- **Staff feeds Communication** — a trained CCA is the one expected to explain the storytelling/upselling narrative that Product and Category Communication signage reinforces.
- **Display feeds Communication** — offer and product talkers are placed *at* the display, so a non-compliant display often means non-compliant communication too.
- **All four report upward through the same chain**: Supervisor → AM → AGM Sales → (in serious/unresolved cases) CEO.

## 6. Master Glossary (Quick Reference)

| Term | Meaning |
|---|---|
| **AM** | Area Manager — primary process owner across all four modules |
| **AGM (Sales)** | Assistant General Manager, Sales — secondary owner / first escalation point |
| **CCA** | Customer Care Associate — front-line store staff |
| **HC / NG** | Home Center — the retail partner; "NG" refers to the brand itself |
| **SOH** | Stock On Hand |
| **MDQ** | Minimum Display Quantity |
| **DRR** | Daily Run Rate (avg. units sold/day) |
| **DOC** | Days of Cover = SOS ÷ DRR |
| **PI Sheet** | Preliminary Indent worksheet, built before the formal PO |
| **PO** | Purchase Order |
| **SO** | Sales Order (punched in ERP to trigger production) |
| **O2D** | Order-to-Delivery process |
| **POD** | Proof of Delivery (manual count/discrepancy log at receiving) |
| **GRN** | Goods Receipt Note (created by the Home Center team; owned by Operations) |
| **RTV** | Return to Vendor/Warehouse |
| **VM** | Visual Merchandising |
| **Planogram** | The store-specific visual map of what product goes where |
| **PDQ** | A small dedicated impulse-purchase display unit/box |
| **NPD** | New Product Development team |
| **EOS** | End of Season Sale (a twice-yearly offer campaign) |
| **Talker / Dangler** | A small shelf sign (talker) or hanging sign (dangler) |
| **General Code** | A catch-all SKU code used when the exact pot/color variant is unavailable — creates a sales-tracking blind spot |

## 7. Open Items Flagged During the Process Review (as of this walkthrough)
These are explicitly *not yet finalized* — good context for a fresher, since you may be pulled into resolving them:
1. **General code tracking gap** — no standardized way yet to trace sales back to the exact SKU/pot variant when substituted under a general code.
2. **Objective staff testing mechanism** — HR is still building a standardized, time-boxed monthly testing process to replace the current, more subjective supervisor-led evaluation.
3. **GRN ownership confirmation** — to be verified directly with the Operations team, since it's a shared stakeholder process.
